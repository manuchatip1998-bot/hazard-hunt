# Hazard Hunt – เกมล่าจุดเสี่ยง (Time Attack)

เกมสำหรับห้องอบรมความปลอดภัย ผู้เล่นต้องชี้จุดอันตรายในภาพพื้นที่ทำงานทั้ง **Unsafe Act (UA)** และ **Unsafe Condition (UC)** ให้ครบก่อนระเบิดเวลาจะระเบิด

## เปิดเล่นในเครื่อง
ดับเบิลคลิก `public/index.html` เพื่อเปิดใน Chrome หรือ Edge ได้เลย ไม่ต้องติดตั้งโปรแกรมและเล่นแบบออฟไลน์ได้
- กด **F** เพื่อเต็มจอก่อนขึ้นโปรเจกเตอร์
- คลิกเมาส์หรือแตะหน้าจอครั้งแรกเพื่อเปิดเสียง (เป็นข้อกำหนดของเบราว์เซอร์)

## กติกา
| เหตุการณ์ | ผล |
|---|---|
| ชี้ถูก | ได้คะแนนตามจุด (ค่าเริ่มต้น 100) และ **+5 วินาที** |
| ชี้ถูกติดกันภายใน 5 วินาที | **คอมโบ x2, x3** |
| ชี้ผิด | **−5 วินาที** และคอมโบหลุด |
| คำใบ้ 💡 | เรดาร์ชี้บริเวณใกล้จุดที่ยังไม่พบ แลกกับ **−10 วินาที** |
| หาครบ | กู้ระเบิดสำเร็จ ได้โบนัส 10 คะแนนต่อวินาทีที่เหลือ |
| หมดเวลา | ระเบิด! แล้วเฉลยจุดที่หาไม่พบทีละจุด |

**ดาว**: หาครบและเหลือเวลาอย่างน้อย 25% ได้ ★★★ · หาครบได้ ★★ · หาได้ 60% ขึ้นไปได้ ★

หลังจบเกม กด **📋 ดูสรุป / เฉลย** เพื่อดูทุกจุดพร้อมคำอธิบายความเสี่ยงและวิธีแก้ไข คลิกที่รายการเพื่อซูมไปที่จุดนั้นในภาพ ใช้ประกอบการคุยกับผู้อบรมได้

### ปุ่มลัดสำหรับวิทยากร
`Space` หยุด/เล่นต่อ · `H` คำใบ้ · `R` เฉลยทั้งหมด · `F` เต็มจอ · `M` เปิด/ปิดเสียง · `Esc` หยุดเกม (กดซ้ำเพื่อออก)

## สร้างด่านจากรูปหน้างานจริง
1. เมนู → **🛠 สร้าง / แก้ไขด่าน** → **＋ ด่านใหม่** แล้วเลือกรูป ระบบจะย่อรูปให้ยาวสุด 1920px อัตโนมัติ
2. เลือกเครื่องมือ **◯ วงกลม** หรือ **▭ สี่เหลี่ยม** แล้วลากครอบจุดอันตรายบนภาพ
3. กรอกชื่อจุด เลือก UA หรือ UC แล้วใส่คำอธิบายความเสี่ยง วิธีแก้ไข และคะแนน
4. ใช้โหมด **🖱 เลือก** ลากเพื่อย้ายโซน ลากจุดสี่เหลี่ยมสีขาวเพื่อปรับขนาด หรือกด `Delete` เพื่อลบ
5. กด **💾 บันทึก** (หรือ `Ctrl+S`) แล้วกด **▶ ทดลองเล่น**

> ข้อมูลด่านเก็บในเบราว์เซอร์ของเครื่องนั้น ใช้ **⬇ Export** เพื่อสำรองหรือย้ายไปเครื่องอื่น แล้วใช้ **⬆ Import** ที่เครื่องปลายทาง (ไฟล์ .json มีรูปฝังอยู่ในไฟล์แล้ว)
> ทำให้โซนใหญ่กว่าวัตถุเล็กน้อย เพื่อให้ผู้อบรมชี้โดนง่ายเมื่อใช้จอสัมผัส

## นำขึ้น Firebase Hosting
```bash
npm install -g firebase-tools
firebase login
cd hazard-hunt
firebase init hosting     # เลือกโปรเจกต์ ใส่ public directory = public, ตอบ No กับ single-page rewrite และ No กับการเขียนทับ index.html
firebase deploy --only hosting
```
`firebase.json` ตั้งค่าไว้ให้แล้ว หลัง deploy ด่านที่สร้างไว้ในเครื่องจะ**ไม่**ตามขึ้นไปบนเว็บ ให้ Export จากเครื่องแล้ว Import บนเว็บ

```
  css/style.css       ธีมและแอนิเมชัน

  js/audio.js         เสียงสังเคราะห์ (ไม่ใช้ไฟล์เสียง)
  js/fx.js            พาร์ติเคิล confetti ระเบิด พลุ และจอสั่น
  js/game.js          เอนจินเกม Time Attack
  js/editor.js        โหมดสร้างและแก้ไขด่าน
  js/app.js           สลับหน้าจอ ตั้งค่า หน้าสรุป และตารางอันดับ
  js/samples/         ด่านตัวอย่าง: โรงงานผลิต, คลังสินค้า, งานก่อสร้าง, สำนักงาน, ห้องครัว, ห้องแล็บเคมี 1-2, อู่ซ่อมรถ, งานเชื่อม, ที่อับอากาศ (ตำแหน่งจุดอันตราย)
  img/                รูปฉากของด่านตัวอย่าง (factory.jpg, warehouse.jpg, construction.jpg, office.jpg, kitchen.jpg, lab.jpg, lab2.jpg, garage.jpg, welding.jpg, confined.jpg)
```
ปรับค่ากติกาได้ที่ `CFG` ใน `js/game.js` (bonus, penalty, hintCost, comboWindow, tolPx)
